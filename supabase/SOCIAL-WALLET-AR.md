# أساس قاعدة بيانات همسات: الغرف والمحفظة والهدايا

هذا التحديث يأتي بعد `0001_identity.sql` ويضيف جداول الغرف والمحفظة وسجل المعاملات والهدايا.

## التطبيق

1. افتحي Supabase ثم مشروع Hamsat.
2. افتحي SQL Editor ثم New query.
3. انسخي محتوى `supabase/migrations/0002_social_wallet.sql` كاملًا.
4. اضغطي Run. يجب أن تظهر رسالة Success.
5. لا تضيفي أي مفتاح سري إلى GitHub أو ملفات المتصفح.

## ما الذي يضيفه

- الغرف: قراءة للمستخدمين المسجلين، وإنشاء وحذف لصاحب الغرفة.
- المحفظة: المستخدم يقرأ رصيده فقط؛ لا توجد سياسة تسمح للمتصفح بتعديل الرصيد.
- المكافأة اليومية: دالة قاعدة بيانات ذرية تمنح 20 عملة مرة كل 24 ساعة.
- الهدايا: كتالوج هدايا، وسجل إرسال واستلام، ودالة آمنة تخصم من المرسل وتضيف للمستلم ضمن معاملة واحدة.
- حساب جديد: ينشئ له trigger ملفًا شخصيًا ومحفظة مع 100 عملة ترحيبية.
- الحسابات الموجودة قبل هذا التحديث تحصل على محفظة تبدأ بصفر، ولا تُمنح مكافأة بأثر رجعي.

## ما لا يفعّله هذا التحديث

هذا التحديث يجهز طبقة البيانات والأمان فقط. لا يربط واجهة التطبيق تلقائيًا، ولا يشغل الصوت المباشر أو مكالمات WebRTC أو رسائل الدردشة أو إشعارات الهاتف أو شراء العملات. يجب ربط الواجهة بهذه الجداول والدوال واختبارها قبل إظهار أن الميزة تعمل.

## الأمان

لا تضعي `service_role` أو أي مفتاح سري في ملفات JavaScript. يستخدم المتصفح فقط Publishable/anon key مع جلسة Supabase وRLS. لا تضيفي سياسات UPDATE أو INSERT مباشرة على جدول wallets أو wallet_transactions.
