# إعداد لوحة إدارة همسات

هذه الخطوات تخص فرع التطوير `build/hamsat-complete-app` فقط.

## ما توفره اللوحة
- إضافة إطارات للمقتنيات مع الاسم والسعر والندرة والصورة.
- إخفاء الإطار أو نشره في متجر المقتنيات.
- إنشاء سجلات ألعاب مع النوع والوصف وأيقونة وإعدادات JSON ونشرها أو إخفاؤها.

**مهم:** تسجيل الألعاب في اللوحة لا يعني أن منطق اللعبة الجماعي أو احتساب النقاط أصبح جاهزاً. لكل لعبة نحتاج تنفيذ شاشة اللعب وقواعدها والمزامنة الحية والتحقق من النتائج على الخادم.

## تفعيل قاعدة البيانات
1. راجعي الملف `supabase/migrations/0011_admin_catalog_and_games.sql`.
2. خذي نسخة احتياطية، ثم طبّقيه يدوياً على مشروع Supabase الصحيح بعد مراجعة السياسات الحالية.
3. امنحي حسابك دور مدير من SQL Editor باستعمال بريد الحساب الذي تسجلين به (استبدلي البريد التجريبي):
```sql
update public.profiles
set role = 'admin'
where id = (
  select id from auth.users
  where lower(email) = lower('YOUR_LOGIN_EMAIL')
);
```
4. تأكدي أن الاستعلام عدّل صفاً واحداً فقط. لا تشاركي كلمة المرور أو مفاتيح API.
5. سجّلي الدخول إلى تطبيق همسات بنفس المتصفح، ثم افتحي `/admin.html`.

إذا لم يكن مجلد التخزين `hamsat-media` موجوداً أو كانت سياساته تمنع الرفع، جهزي bucket وسياسات رفع آمنة للمدير قبل استخدام صور الإطارات.

## الأمان
- الدور الافتراضي لكل مستخدم هو `user`.
- لا يستطيع المستخدم ترقية نفسه من الواجهة؛ تعيين المدير عملية SQL إدارية فقط.
- سياسات RLS تمنع غير المديرين من إدارة الإطارات والألعاب.
- لا تطبّقي migration على الإنتاج قبل فحص النسخة الاحتياطية والسياسات الموجودة.
