# Hamsat | همسات

مشروع تطبيق اجتماعي عربي للدردشة الصوتية.

## الهدف
تطوير تطبيق عربي بواجهة RTL وتصميم فاخر باللون البنفسجي الداكن والذهبي.

## الوظائف المطلوبة
- حسابات المستخدمين والملفات الشخصية.
- غرف صوتية مباشرة.
- العملات والهدايا.
- الرسائل الخاصة والإشعارات.
- الوكالات والمضيفون.
- لوحة الإدارة والأمان.

## الحالة الحالية
هذا المستودع مخصص لملفات المشروع والتوثيق. الوظائف المذكورة متطلبات تطوير وليست جميعها منفذة أو مختبرة بعد.

## التعاون
يمكن للشريك التقني مراجعة المشروع والمساهمة في تطويره.
