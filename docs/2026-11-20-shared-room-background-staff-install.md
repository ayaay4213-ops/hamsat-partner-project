# تحديث همسات — خلفية الغرفة المشتركة، المسؤولون، والتثبيت

## نطاق الفرع
هذا العمل موجود على فرع مراجعة منفصل:
`work/hamsat-room-background-staff-pwa-2026-11-20`

لا يغيّر رابط Production ولا يبدّل قاعدة Supabase الحية. لا تدمجيه في الفرع الرئيسي قبل مراجعة الاختبارات والموافقة.

## 1) خلفية المايكات المشتركة
- أضيفت واجهة «تغيير خلفية المايكات» لكل عضو داخل الغرفة، وليس لصاحب الغرفة فقط.
- يستطيع العضو اختيار صورة PNG/JPG/WEBP من هاتفه (حد 5MB) ومعاينتها قبل الحفظ.
- بعد الحفظ، تُخزّن الخلفية على مستوى الغرفة في `room_backgrounds`، وتصل التغييرات للموجودين عبر Supabase Realtime.
- تبقى الخلفية محفوظة بعد خروج العضو الذي اختارها أو مغادرته الغرفة.
- خلفية المايكات مستقلة عن غلاف الغرفة.
- صلاحية تغيير الخلفية في سياسة قاعدة البيانات لأعضاء الغرفة فقط؛ لا يمكن لزائر غير منضم تعديلها.

## 2) المسؤولون محدودو الصلاحيات
أضيف أساس قاعدة البيانات في migration `0062_shared_room_backgrounds_and_staff_roles.sql`:
- تعيين المسؤولين محصور بالسوبر أدمن.
- الصلاحيات المسموحة مبدئياً: `room_moderation`, `report_review`, `member_support`, `event_management`.
- لا توجد صلاحيات مالية أو للمحفظة أو السحب أو الوكالات أو تعيين مسؤولين آخرين.
- كل تعيين يسجل في `staff_audit_log`.
- يوجد helper باسم `has_staff_permission` لفحص الصلاحية من الخادم.

**حالة التنفيذ:** أضيفت لوحة تعيين الصلاحيات داخل لوحة السوبر أدمن، وأضيفت صفحة مستقلة للمسؤول تعرض الصلاحيات وتتيح مراجعة البلاغات عند امتلاك `report_review` عبر RPC يفحص الصلاحية ويسجل الإجراء. صلاحيات إشراف الغرف والدعم والفعاليات تظهر كصلاحيات مخصصة، لكن أدواتها التشغيلية لم تُفعّل بعد؛ وبالأخص كتم الصوت والطرد يحتاجان تحديثاً آمناً لوظائف LiveKit على الخادم. لا تُمنح هذه الصلاحيات قدرة تنفيذية قبل اكتمال ربطها واختبارها.

## 3) تثبيت الهاتف
- المشروع يحتوي مسبقاً على Web App Manifest وService Worker وأيقونات التطبيق ووضع standalone.
- أضيف مسار إرشادي على Android إذا لم يرسل المتصفح حدث التثبيت التلقائي.
- التخزين المؤقت الحالي يجهز غلاف التطبيق والملفات التي يطلبها المتصفح بعد تحميلها؛ لا يعني أن الصوت والرسائل وباقي الخدمات تعمل دون إنترنت. وظائف الاتصال الحي تحتاج الإنترنت.

## ما لم يحدث
- لم تُطبّق migrations 0060–0062 على Supabase. قاعدة البيانات الحية حالياً عند 0059، لذلك يجب مراجعة 0060 و0061 أولاً ثم تطبيق 0062 على بيئة اختبار قبل أي نشر وظيفي.
- لم يُنشر Preview أو Production من هذا الفرع.
- لم يُختبر التثبيت على هاتف Android فعلي بعد.
- لم يُختبر تحديث الخلفية بين هاتفين مستقلين بعد.

## قبل نشر Preview
1. مراجعة migrations 0060 و0061 و0062 ونسخة احتياطية من قاعدة البيانات.
2. تطبيقها على بيئة اختبار منفصلة، لا على قاعدة الإنتاج.
3. التأكد من إتاحة جدول `public.room_backgrounds` عبر Data API مع إبقاء RLS مفعلاً.
4. اختبار عضوين داخل الغرفة: اختيار خلفية، تحديث فوري عند الطرف الآخر، الخروج والعودة، وإزالة الخلفية.
5. اختبار مراجعة البلاغات بحساب مسؤول وحساب عادي للتأكد من منع الوصول غير المصرح به.
6. تحديث وظائف LiveKit لتقبل صلاحيات إشراف الغرف المحددة فقط، ثم اختبار الكتم والطرد وسجل التدقيق.
7. اختبار تثبيت همسات وفتحها من الشاشة الرئيسية على Android.
